安装

一条 npm 命令，即可开始

无需克隆仓库，安装器会自动完成依赖安装与初始化，并引导你接入第一个 Agent 平台。执行数据全部留在你自己的机器上。

运行要求 Node.js 20.9+ 默认端口 3000 数据库 SQLite，零依赖 协议 Apache-2.0

安装步骤

  1. 准备 Node.js 环境

    安装 Node.js 20.9 或更高版本（自带 npm），然后确认版本。

    $ node -v

  2. 安装并初始化

    通过 npx 运行安装器，自动完成依赖安装与初始化，并引导接入第一个 Agent 平台。

    $ npx agent-insight install

  3. 启动服务

    启动 Agent Insight 服务，默认监听 3000 端口。

    $ npx agent-insight start

  4. 打开看板并登录

    在浏览器访问 http://localhost:3000，输入邮箱即可登录，随后按页面上的“快速开始”完成模型注册与 Agent 接入。

    http://localhost:3000

常用命令

npx agent-insight install安装与初始化
npx agent-insight start启动服务
npx agent-insight status查看状态
npx agent-insight stop --port 3000停止服务

数据与升级

  • 数据目录~/.agent-insight/data
  • 升级方式重新运行安装命令

版本与发布说明以 AtomGit Releases 为准。
