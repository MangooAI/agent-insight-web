ANSE SIG 是什么

ANSE SIG（AI-Native Software Engineering SIG）是 openEuler 社区的 AI 原生软件工程 SIG。其定位是基于 AI 原生软件工程范式，为企业级软件交付提供可控、可靠、可演进的解决方案。如果你也认同这套范式，欢迎加入 ANSE SIG，一起把 Agentic Engineering 工程化。

从第一个 PR 开始

贡献流程遵循 openEuler 社区规范：签署 CLA、先讨论后实现、CI 通过后合入。

1

注册并签署 CLA

向 openEuler 仓库贡献需签署 openEuler CLA。

2

读贡献指南

了解分支模型、提交规范与 AGENTS.md 约定；文档贡献同样走 PR 流程。

3

认领 Issue

在 Issues 中筛选合适任务，先留言认领并简述思路；较大特性先在 Discussions 对齐。

4

开发、测试、提 PR

从工作分支开发，提交前运行 npm run test 并更新相关文档；PR 说明目的与验证结果。

从一条 Issue 开始

一个缺陷报告、一段文档修订、一个评估器实现，都算数。
