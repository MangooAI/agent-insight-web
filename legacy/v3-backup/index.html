让生产级 Agent 越用越好：Agent Insight 构建覆盖全生命周期的可靠性保障能力，行为可观测、质量可度量、故障可定位、能力可进化。

立即安装

关键能力

观测、验证、防护、改进闭环：能完成一次任务，不等于能持续、可控地交付。

观测

看清执行过程：还原 Agent 层、MaaS 网关层到推理层的端到端执行链路，多视图全局分析 Agent 行为轨迹。

验证

量化能力与风险：结合多维评测和故障注入，评估任务效果、运行稳定性与容错恢复能力，验证优化成效。

防护

及时发现并处置异常：通过运行时故障感知与分级干预，阻断故障传播，支持任务恢复，让执行过程稳定可控。

改进

让问题驱动持续优化：基于轨迹证据定位根因，结合评测与诊断结果实现策略调优、可靠性增强，持续提升 Agent 能力。

实验流程 · 数据演化 · 评测详情

Agent 可靠性:量化能力、识别风险、指导优化

  • 评测资产 → 评测执行 → 评测结果:统一指标、数据与工具,全程可追溯
  • 故障注入:Skill 注入、提示词干预、运行时拦截改写;多维评估结果、轨迹、韧性、安全
  • 预置评测集覆盖 25 类故障模式、29 个注入场景,随故障目录持续同步

RAS 架构 · 评测详情

智能诊断:一键定位超长轨迹故障根因

  • 三层取证机制:确定性扫描全量步骤,模型只做有界查询,超大内容按需外部检索
  • 五模块语义归因:记忆、反思、规划、动作、系统独立判定,每条结论必引用证据
  • 诊断能力可扩展、可核验:一键诊断,10 分钟出结论,根因归因准确率 ≥ 80%

认知层次 · 多层架构 · 诊断界面

智能优化:问题驱动迭代,多级验证保障改进质量

  • 算子归并:分层去重、按频次分级,把海量问题收敛为可落地的优化清单
  • 编辑范围约束:基线快照比对、误删自动恢复、改动超限告警
  • 自验证闭环:结构、真值、行为三级校验,任一失败自动回退重写
