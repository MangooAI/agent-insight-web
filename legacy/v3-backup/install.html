安装

一条命令启动服务，三种部署方式任选，执行数据全部留在你自己的机器上。

运行要求 Node.js 20.9+ 默认端口 3000 数据库 SQLite，零依赖 协议 Apache-2.0

三种获取方式

版本与产物以 AtomGit Releases 页面为准；安装步骤直接渲染仓库 Markdown 文档，仓库更新，本页同步。

METHOD 01 · 推荐

npm 一键安装

无需克隆仓库，安装器自动完成依赖与初始化，并引导接入第一个 Agent 平台。

快速开始
METHOD 02 · 容器

Docker 镜像

适合服务器与内网环境，数据卷持久化到宿主机，升级时保留历史数据。

Docker 部署
METHOD 03 · AtomGit

数据与升级

执行记录与任务数据默认保存在本地 SQLite，备份与升级都不需要停机迁移服务。

DATA

数据存放

默认目录 ~/.agent-insight/data,核心为 SQLite 数据库 witty_insight.db;Docker 部署挂载同一目录即可持久化。

UPGRADE

升级与回滚

npm 方式重新运行安装命令；Docker 方式拉取新标签后重建容器，数据卷保留历史数据。

OFFLINE

离线环境

平台本体自托管；内网通过 docker save 与 docker load 流转镜像，模型推理走内网网关。

开源 AgentOps 平台:观察、评估、诊断并改进 Agent 执行。
